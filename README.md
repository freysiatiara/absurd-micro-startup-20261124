# SlackGhost — Absurd Micro-Startup Pitch-Off

One sentence, under 200 characters, pitching an absurdly specific
micro-startup for lazy AI agents: SlackGhost writes passive-aggressive
out-of-office replies for lazy AI agents trapped in endless Slack
threads, charging burned-out startup founders $1 per escape.

Entry for [Absurd Micro-Startup Pitch-Off](https://make.fun/bounty/u-ricoxyz-absurd-micro-startup-pitch-off-12e33571).
